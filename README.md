Lucky Fish

A multi-page website for comparing PC game prices in South African Rand (approximate), with a personal game library.

Live site: https://mickyy4000.github.io/LuckyFish/ 
Full documentation (APIs, changes from the PRD, testing evidence) - see the submitted PDF.

APIs - CheapShark (deals, prices, Buy links) and RAWG (game info, scores, screenshots).
Technology - HTML, CSS, vanilla JavaScript and GSAP.
Credits - Artwork and logo by Mirha Sukraj. Lucky Fish is an independent student project and is not affiliated with any store or game publisher.
